# Future Academy — Campus Companion Portal

An all-in-one responsive web application built for Future Academy students. This portal integrates the **Course Registration System** and the **University Cafeteria Menu** into a single interface.

---

## 📌 Project Features

### 1. Academic Course Registration Portal
- Displays all assigned semester courses with credit hours and respective faculty members.
- Interactive enrollment modal dynamically captures course selection.
- Clear grid display adapting across mobile, tablet, and desktop views.

### 2. University Cafeteria Ordering System
- Categorized menu layout: **Breakfast**, **Lunch**, and **Drinks**.
- Visual badges for popular dishes, new items, and discounts.
- Interactive order form with item selection, quantity adjustment, and custom requests.

### 3. Campus Branding & Official Links
- Direct link integrated to the official **[Future Academy Facebook Page](https://www.facebook.com/share/196P9bQ8Yk/)**.
- Student portfolio details (Zeidan Mahmoud, student email, and official college support phone numbers).
